# ESP32 AirPlay & Bluetooth 实时滚动歌词桌面音箱

基于 **ESP32-WROVER-E (8MB PSRAM)** 的开源智能音频桌面摆件。支持通过 **苹果 AirPlay 1 (RAOP)** 及 **手机/电脑经典蓝牙 (A2DP)** 无线播放音乐（完美兼容 Apple Music 与 YouTube Music），外接 **3.5 寸 480×320 SPI 彩色大屏幕**，实时通过 **[lrc.cx (LrcAPI)](https://docs.lrc.cx/docs/QuickStart/)** 官方公开服务与 **LRCLIB** 双源引擎拉取歌词并同步高亮滚动显示。

支持 **真双声道立体声 (True Stereo)** 输出、**双 18650 锂电池并联超长续航（搭配 LX-LBC3A 常开 5V 充放板与带灯金属自锁开关）** 以及 **手机免密热点动态 Web 网页配网（Captive Portal 强制门户）**，无需插电脑改代码，随时随地手机一键配网并永久保存在芯片内部！

> 📖 **完整 8 大件保姆级图文制作手册**：请查阅 **[全流程制作与使用手册 (MANUAL.md)](MANUAL.md)**，包含 8 大件 1:1 实物焊盘接线图、5 脚发光金属开关接法、双声道功放接法与烧录指南。

## ✨ 核心特性

- **真双声道立体声 (True Stereo) & 双 18650 超长续航**：
  - **双路 MAX98357A 硬件解算**：支持并联双功放与两只 4Ω 3W 64mm 全频扬声器，通过 `SD_MODE` 引脚硬件分离左右声道，实现宽广真立体声音场。
  - **双 18650 并联 + 常开 5V 电源系统**：采用双节 18650 并联（5200~6800mAh）搭配 **LX-LBC3A (3A 充电 / 2.4A 固定常开 5V)** 充放电主板与 **12mm 白色环形灯自锁金属开关**，按下即开机亮灯，弹起即彻底断电，续航长达 8~12 小时。
- **3.5 寸 480×320 大屏实时滚动歌词 (Layout A 布局)**：
  - 屏幕呈现 **5 行平滑滚动歌词**，当前演唱行以青蓝色 (`#00D2FF`) 加粗高亮显示。
  - 顶部显示音源图标（AirPlay / 蓝牙 / Wi-Fi 状态），底部显示已播时间 / 总时长进度条。
  - 配网时屏幕自动切换为清晰的引导提示（显示热点名与 IP）。
- **双无线音频输入 (双模免切换)**：
  - **Apple AirPlay 1 (RAOP)**：支持 iPhone、iPad、Mac 在控制中心一键投屏，44.1kHz 16-bit 无损/CD 级传输。
  - **经典蓝牙 A2DP Sink**：通用手机、电脑蓝牙配对连接，支持 AVRCP 播放控制与歌曲元数据回传。
  - **智能音频仲裁**：AirPlay 优先抢占，AirPlay 开始播放时自动暂停蓝牙，停止后自动恢复。
- **动态 Web 网页配网 (Captive Portal / WiFiManager 体验)**：
  - **免密热点自建**：新机或更换 Wi-Fi 环境时，自动广播免密热点 **`ESP32-Lyrics-Setup`**。
  - **手机自动弹窗**：手机连上热点后自动弹出暗黑风格配置网页（亦可访问 `192.168.4.1`），列出附近扫描到的 2.4G Wi-Fi。
  - **NVS 永久记忆**：选网输入密码后自动保存至 ESP32 内部 Flash（Preferences），重启秒连，永不丢失。
- **高可用双源自动级联歌词引擎**：
  - **首选源 (Primary)**：官方公开 **[lrc.cx (LrcAPI)](https://docs.lrc.cx/docs/QuickStart/)** 接口（`https://api.lrc.cx/lyrics`），聚合 QQ 音乐、网易云、酷狗及 Apple Music，华语/流行/动漫曲库匹配率极高。
  - **备选兜底 (Fallback)**：若 `lrc.cx` 未命中或网络波动，Core 1 自动无缝切换至 **LRCLIB**（`https://lrclib.net`）进行二次检索。
- **FreeRTOS 双核高效调度**：
  - **Core 0 (`CORE_AUDIO`)**：专职负责 Wi-Fi、蓝牙协议栈、AirPlay RTSP/RTP 服务及 I2S DMA 音频推流，杜绝卡顿爆音。
  - **Core 1 (`CORE_UI`)**：负责 LVGL 8.x 界面渲染、网络歌词拉取及 10Hz 播放进度与歌词对齐计时器。
  - **8MB 片外 PSRAM 深度优化**：动态将歌词缓存与 LVGL 帧缓冲挂载至 PSRAM，保障内部内存充沛。

## 🔌 硬件接线引脚图 (Wiring Pinout)

> [!WARNING]
> **绝对避坑原则**：ESP32-WROVER-E 模组内部已将 **GPIO 16** 和 **GPIO 17** 用于连接外部 PSRAM 芯片，**严禁外部引线连接 GPIO 16 和 17**！本项目已在编译期和代码中完全避开这两个引脚。

### 1. 电源系统 (`LX-LBC3A` ↔ 电池盒 ↔ 金属带灯开关)
| 起点 | 终点 | 说明 |
| :--- | :--- | :--- |
| **3.7V 并联电池盒 红线 (`+`)** | **电源板 `B+` 焊盘** | 锂电池正极输入 *(首次接好插一下 Type-C 充电器激活)* |
| **3.7V 并联电池盒 黑线 (`-`)** | **电源板 `B-` 焊盘** | 锂电池负极输入 |
| **电源板 `5V` 正极焊盘** | **金属开关 `C` 脚** | 常开 5V 送入自锁开关公共端 |
| **金属开关 `NO` 常开脚** | **整机 `5V` 总线 + 开关 `+` 脚** | 按下开关输出 5V 给 ESP32 `5V(VIN)`、双功放 `VIN` 并点亮环形灯 |
| **电源板 左上角负极焊盘** | **整机 `GND` 总线 + 开关 `-` 脚** | 全系统共地（ESP32 `GND`、双功放 `GND`、屏幕 `GND`、开关灯 `-`） |

### 2. 双声道立体声功放 (2× MAX98357A 并联接线)
| MAX98357A 引脚 | 左声道功放 (Left) | 右声道功放 (Right) | ESP32-WROVER-E 引脚 / 说明 |
| :--- | :--- | :--- | :--- |
| **VIN** | 接整机 5V 总线 | 接整机 5V 总线 | 必须接 5V 保证功放推力 |
| **GND** | 接整机 GND 总线 | 接整机 GND 总线 | 系统共地 |
| **BCLK** | 并联到 **GPIO 25** | 并联到 **GPIO 25** | 位时钟 (Bit Clock) |
| **LRC** | 并联到 **GPIO 26** | 并联到 **GPIO 26** | 声道选择时钟 (Word Select) |
| **DIN** | 并联到 **GPIO 27** | 并联到 **GPIO 27** | I2S 串行音频数据 |
| **GAIN** | 悬空 | 悬空 | 默认 9dB 增益 |
| **SD_MODE** | **串 100kΩ 电阻到 5V** | **串 100kΩ 电阻到 GND** | 硬件解算声道：>1.4V 解码左声道，0.16~0.77V 解码右声道 |

### 3. 3.5 寸 SPI TFT 彩色液晶屏 (480×320)
| 屏幕引脚 | ESP32-WROVER-E 引脚 | 说明 |
| :--- | :--- | :--- |

| **GND** | **GND** | 电源共地 |

## 🚀 快速烧录与使用（无需写死 Wi-Fi 密码！）

完整分步教程请阅读 **[MANUAL.md](MANUAL.md)**：

1. **一键烧录**：
   ```bash
   git clone https://github.com/qingtian6325-lang/ESP32-Airplay-Music-With-Lyrics.git
   cd ESP32-Airplay-Music-With-Lyrics
   pio run -e esp32dev --target upload
   ```
2. **手机动态网页配网**：
   - 按下金属开关开机，手机连接免密热点 **`ESP32-Lyrics-Setup`**。
   - 手机自动弹出配网网页（或浏览器打开 `http://192.168.4.1`），点选家里的 Wi-Fi 输入密码保存，永久记忆在芯片内部。
3. **无线听歌**：
   - **AirPlay**：iPhone 控制中心点选 **`ESP32-Lyrics-Speaker`** 无损投送。
   - **蓝牙**：手机蓝牙搜索配对 **`ESP32-Lyrics-Speaker`** 播放任意音乐 App。
